# 合同模板 V3(2026-09-25)——精简 + 合法化改版

- 输入:`v2-a4-template.docx`(线上合同的A4排版修订版) + GasCan母亲(甲方)提供的、用了多年的纸质旧合同(照片,含真实个人信息,**不入库**)。
- 产出:`v3-template.docx`(由 `build-v3.js` 生成,需 `npm i docx` 后 `node build-v3.js v3-template.docx`)。
- 本次只交付docx,**系统合同生成代码(`apps/server/src/contract-pdf/`)未改**,线上仍是v2。移植到代码时微签盖章坐标需重新校准。

## GasCan 确认的方向(2026-09-25)
1. "长期可用" = 模板本身用2年以上不用频繁改(不是单份合同签2年以上)。
2. 甲方 = 个人(GasCan母亲),转租出租人;产权人是公司(GasCan为法人),**甲方与产权人的租赁合同尚未签署**。市场主体登记问题以后再说。
3. 原则:合法、在纠纷里站得住;不是一味偏向甲方。
4. 交付物:优化后的docx。
5. 甲方反馈v2太冗杂,借鉴旧纸质合同的简洁结构。

## 结构变化
- 信息区改为一张8行表;正文10条;附件从5个合并为1个《房屋交接清单》。
- 删除:附件一(权利依据,并入第一条1款一句话)、附件二(同住人,并入信息区)、附件四(安全承诺书,要点并入第四条)、附件五(费用规则,并入第二条3款)、买卖不破租赁/优先承租权/不定期租赁(法律直接适用,不写也有效)、电子证据/哈希值等技术性表述、逾期日万分之五违约金(旧合同也没有,简化为"超期可解除+违约金")。
- 去掉所有绑定软件/平台的措辞("签约平台站内信""租客端在线支付""系统退回")。

## 法律风险修正(对v2和旧合同)
| 原条款 | 问题 | V3处理 |
|---|---|---|
| v2 2.6"仅完全无法居住才可减租" | 与民法典729条冲突 | 删除 |
| 旧合同"房内伤亡出租人不承担任何责任" | 民法典506条:人身损害免责条款无效 | 改为按过错分担(4.4) |
| 旧合同"甲方所在地法院管辖" | 房屋租赁纠纷按不动产所在地专属管辖 | 改为房屋所在地法院 |

| v2 电子通知"未被系统明确退回的,发送后N小时视为送达" | 措辞依赖实现 | 短信/微信发出满24小时视为送达(固定写死) |

## 占位符(共31个;与v2同名的沿用,变化如下)
- 新增:`【违约金月数】`(合并v2"提前退租违约金月数"+甲方违约的"【7】日",对应 `defaultPenaltyMonths`)、`【续租通知天数】`(对应 `defaultRenewNoticeDays`)。
- 合并删除:`变相转租认定天数`/`累计居住天数` → 仅保留 `【连续居住天数】`;`违约补救期限` → 并入 `【逾期可解除天数】`;`押金支付截止日` → 并入 `【首期支付截止日】`;`首期租金`、`不续租通知天数`、`电子通知送达小时数`、`面积`、`出租范围`、`签署时间` 删除。
- 共同居住人改为信息区一行文本 `【共同居住人姓名及身份证号;无则填"无"】`。

## 待确认/风险提示
- **甲方与产权人(公司)的租赁合同需尽快签署,且须明确允许转租、租期覆盖对外合同期限**;V3第一条1款依赖这份文件存在。
- 押金金额无上限约定;旧合同实填"押2"(照片)——扩到300间、可能被认定为规模化出租时,需复核届时的押金相关规定。
- 预览限制:本环境LibreOffice缺Writer组件,只能用mammoth→HTML→Chromium近似预览(不含加粗/分页),正式使用前请在Word/WPS里打开核对排版。
