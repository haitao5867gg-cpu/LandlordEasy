## 二、用户视角审阅
**租客**:最关心的是"付多少、什么时候付、付给谁、押金怎么退、提前走要赔多少"。V3 里这些散落在信息表、2.1、第三条、第七条四处。
→ V4 信息表集中写明金额、周期、收款人、付款时间;押金拆成"退还时间 / 可扣项目 / 不扣项目"三款,一眼能看懂。

**房东(甲方)**:合同要像以前的纸质合同一样好填、好找。
→ 条款顺序跟旧合同一致(房屋→租金→押金→安全→维修→转租→违约→退房→其他);第七条违约情形改成(1)~(5)逐行列出。

**版式**(GasCan 反馈"密密麻麻、布局乱"):
- 正文字号 10.5pt → 11pt,行距约1.25 → 1.45倍;条与条之间留白,条标题用黑体并加细分隔线
- 款号用悬挂缩进,换行后文字对齐,不再跟序号挤在一起
- 当事人信息做成 姓名 / 身份证号 / 电话 三列表格;租赁要点单独一张表
- 全文分为"一、基本信息 / 二、合同条款 / 三、签署"三大块;签署前的重要提示放进灰底框;附件单独一页
- 页数 4 → 5(换来可读性;正文约3页半)

## 修改(2026-09-25):手机端显示适配
GasCan 在 iPhone 上用系统自带预览打开 docx,表格缩成一团、签名区出现黑框、分页处出现"□"、页码空白、款号后空一大段。
原因是 iOS 预览只支持 Word 格式的一个子集,V4 用了它不支持的写法。改法(每一项都换成通用写法,Word/WPS/LibreOffice 效果不变):
| 手机上的问题 | 原因 | 改法 |
|---|---|---|
| 表格按内容缩窄,只占半屏 | 表格是"自动调整"布局 | 改为固定列宽布局(tblLayout fixed) |
| 签名区出现黑框 | 用"无边框表格"排两栏签名,iOS 忽略无边框设置 | 签名改为上下两行普通段落+下划线 |
| 重要提示框边框很粗 | 单格表格 | 改为带底色和细边框的段落 |
| 附件前出现"□" | 单独的分页符段落被当成字符显示 | 改为附件标题"段前分页" |
| "1.""（1）"后面空一大段 | 手写序号+制表符,iOS 不认制表位 | 改用 Word 原生编号,每条从1重新编号 |
| 页脚"第 页／共 页"是空的 | iOS 不计算页码域 | 页脚改为"住房租赁合同(模板V4) 页码",页码显示不出来时也不会留下空框架 |
| 表格线又黑又粗 | 深灰色边框 | 边框改浅灰 BFBFBF |

产品建议:租客实际是在手机微信里看**系统生成的PDF**,不是看 docx;PDF 在任何手机上显示都一致。docx 只作为模板底稿给家人审阅,对外发送/手机查看一律用 PDF。
