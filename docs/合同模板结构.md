# 房屋租赁合同 — 固定条款结构（M19电子签约用）

> 来源：GasCan 于 2026-09-01 提供的手写填好的真实合同扫描件（1份正文+1份附件《租赁房屋安全责任承诺书》）。**原始PDF包含真实租客的姓名/身份证号/电话/签名，不入库**；这份文档只整理印刷体的固定条款结构和识别出的动态字段清单，不含任何真实第三方个人信息。原始文件路径不记录在本仓库任何地方。

## 正文结构（共1页）

标题：房屋租赁合同（右上角有"No.____"编号栏）

```
出租人(甲方)：____ 身份证号：____ 电话：____
承租人(乙方)：____ 身份证号：____ 电话：____
根据《中华人民共和国民法典》、《中华人民共和国城市房地产管理法》及其他有关法律规定，
在平等、自愿、协商一致的基础上，甲、乙双方就下列房屋的租赁达成如下协议：
```

**第一条 房屋基本情况**
因乙方【居住/经营】需求，甲方现将坐落于【房屋地址】的房屋（用途打勾：□住宅 □合仓 □办公室）出租给乙方使用。甲方必须保证该房屋权属清晰，同时保证乙方租赁期内对该房屋的使用权。

**第二条 租赁期限**
租用期限从【起租日期】至【到期日期】，租期【N】年。

**第三条 租金约定**
1. 该房屋月租金人民币【大写金额】元整（小写：【数字金额】元），该租金不含税费，相关税费由承租人另行承担，租金按【支付周期，如"季付"】支付，乙方负责在每次房租到期前【N天，样本填3天】天缴纳下次房租给甲方。如乙方拖欠租金超过【N天，样本填5天】天，甲方有权通知乙方立即解除合同，乙方应向甲方赔偿【N个月，样本填1个月】租金作为违约金。房间内的物品由甲方进行打包清理，费用由乙方承担。
2. 租赁期内水、电、燃气、网络、暖气、物业、卫生等费用均由乙方承担，乙方预付押金【押金金额】元整。等租赁期满，甲乙双方结清所有费用后，多余押金退还乙方，押金不计利息。
3. 租赁期间乙方不得中途退房，如需退房，需提前一个月通知甲方，并赔偿甲方【N个月，样本填1个月】的房屋租金作为违约金。

**第四条 房屋安全管理、双方权利与义务**（4款，纯固定文本，无变量：禁止电动车/电池充电室内充电；违法经营后果；承租人自担安全责任；拆迁/规划征收处理方式）

**第五条 违约责任**（3款，纯固定文本，无变量：不得擅自改动结构；不得转租转借；甲方违约赔偿标准）

**第六条 其他条款**
1. 租赁期满或解除后，退房清洁费【金额，样本填110元】，遗留物品视为丢弃。
2. 续租需提前【N天，样本填30天】向甲方提出。
3. 自租房日起电表底数【N】；水表底数【N】；天然气底数【N，样本填"无"】
4. 屋内主要设施：空调( ) 冰箱( ) 洗衣机( ) 热水器( ) 燃气灶( ) 电视( ) 淋浴器( ) 油烟机( ) 床( ) 桌子( ) 椅子( ) 沙发( ) 其他：____（12项固定选项打勾，跟 `ContractSigningTask.facilities` 已有字段对应）
5. 其他补充条款：【自由文本，样本填"合同内的水价物价不予以扣款"这类个例备注】
6. 附件与正文同等法律效力；合同一式两份；违约纠纷由甲方所在地法院管辖（纯固定文本）

```
甲方签字(按手印)：____  日期：____
乙方签字(按手印)：____  日期：____

房屋租金/押金收据
收到承租人从【起租日期】至【到期日期】房屋租金人民币大写【金额】元
小写：【金额】元，另收押金【金额】元整（押金不计利息），特此收据
收款人签字：____  日期：____
```

## 附件结构（共1页）：《租赁房屋安全责任承诺书》

纯固定文本，9条承诺条款（严格履行合同/用水安全/用电安全/用气安全/环境卫生/爱护房屋/文明礼貌/禁止高空抛物翻越护栏/遵守法律不存违禁品），无任何变量字段，末尾"承诺人签字+日期"。

## 识别出的动态字段清单（对照现有数据模型）

| 合同里的位置 | 数据来源 | 现状 |
|---|---|---|
| 甲方姓名/身份证号/电话 | **固定不变**（设计已定：甲方名义写死，不因租约而变） | 需要一次性配置存哪，待确认（不建议硬编码进代码，因为身份证号是PII） |
| 乙方姓名/身份证号/电话 | `Tenant.name`/`Tenant.idCard`/`Tenant.phone` | idCard当前可选，需改必填+格式校验（已确认要做） |
| 房屋地址 | `Room`/`Building` | 已有 |
| 房屋用途(住宅/合仓/办公室) | 无对应字段 | **待确认**：是否所有房源都固定"住宅"可以写死，还是要做成变量 |
| 起租/到期日期 | `Lease.startDate`/`Lease.endDate` | 已有 |
| 租期(年数) | 可由起止日期算出 | 不需要额外存 |
| 月租金(大写+小写) | `Lease.rent`（小写）；大写需要程序做"数字转中文大写金额" | 大写转换是新增小工具函数 |
| 支付周期 | `Lease.payCycle` | 已有 |
| 逾期天数容忍(样本"5天")、违约金月数(样本"1个月")、清洁费(样本"110元")、续租提前通知天数(样本"30天") | 合同标准条款里的具体数字 | **待确认**：是所有租约统一的固定值(写死进模板)，还是要做成可配置变量 |
| 电表/水表/天然气底数 | `ContractSigningTask.waterMeterReading`/`electricityMeterReading`/`gasMeterReading` | 已有 |
| 屋内设施12项 | `ContractSigningTask.facilities` | 已有 |
| 其他补充条款(自由文本) | 无对应字段 | **待确认**：是否需要新增一个自由文本字段 |
| 合同编号(No.) | 无 | **待确认**：用系统自己的编号(如leaseId/ContractSigningTask.id)还是不需要 |
