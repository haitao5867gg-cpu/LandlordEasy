# 房东使用指南

> 本指南面向公寓的房东家人,覆盖日常经营的全部操作。系统在微信里使用,不需要安装任何 App。
> 有任何页面报错或和本指南描述不一致的情况,请截图发给系统维护人员。

---

## 1. 怎么进入系统

**微信进入(推荐)**:打开微信公众号,点底部菜单里的「房东端」,会自动登录,直接进入工作台。

- 登录是自动的,不需要输密码。如果提示"微信授权登录",点一下蓝色按钮即可。
- 只有在房东白名单里的微信号才能进入,别人的微信打开会提示无权限。

## 2. 认识界面

进入后底部有 4 个按钮,是整个系统的主要入口:

| 按钮 | 用途 |
|------|------|
| 工作台 | 每天先看这里:空置、到期、逾期、待确认收款、待处理申请的数字汇总 |
| 房间 | 全部房间的列表和管理 |
| 账单 | 全部账单的列表和管理 |
| 我的 | 报表、维修记录、支出、系统设置的入口 |

**切换公寓**:屏幕最顶部有一行「当前:全部公寓」,点它可以切换到某一栋公寓单独查看。切换后,所有页面的数据都只显示这个公寓的。日常建议保持「全部公寓」。

## 3. 第一次使用前的准备(只做一次)

进入「我的 → 系统设置」,逐项检查:

1. **公寓管理**:添加公寓(如"鸿翼人才公寓")。
2. **楼栋管理**:添加楼栋(如 Q 栋、R 栋),归属选好公寓。
3. **合同签约设置**:填写合同甲方信息(公司名、统一社会信用代码等)。**这里没填,后面生成电子签约会报错**。另外可以配置"默认物品清单"(入住交接时一键预填的物品,如:空调 1、冰箱 1、床及床垫 2)。
4. **提醒参数**:提前几天提醒租客交房租(默认 3 天)、逾期后隔几天再提醒(默认 3 天)。一般不用改。
5. **收款码**:上传你的微信收款码图片,租客线下扫码转账时用。
6. **群发通知**:给租客发通知(如台风预警)用,后面细说。

## 4. 新建房间

**位置**:底部「房间」→ 右上角「+」

1. 选择楼栋。
2. 填起始房号(如 301),结束房号留空就只建 1 间;填了(如 310)就批量建 301~310 一整批。
3. 点「提交」,提示"成功创建 N 间房"。已存在的房号会自动跳过,不会重复建。

## 5. 新签租约(最重要的一步)

**入口**:「房间」→ 点开一个**空置**房间 → 右上角「新签租约」。

> 只有空置房间能新签租约。已租房间的入口在换租审批通过后自动打开。

表单从上往下填:

**租客信息**(三项都必填):
- 姓名、手机号(11 位)、身份证号(15 或 18 位)。填错格式会提示,提交不出去。

**租约信息**:
- **起租日**:点开日历选,默认今天。
- **租期**:点选 1 个月 / 3 个月 / 6 个月 / 1 年 / 自定义。**到期日自动算好**,不用手填(比如 1 年期:9/20 起租 → 次年 9/19 到期)。
- **月租金**:填数字(元)。
- **押金**:**会自动跟着月租金填上**,押金和租金不一样时手动改掉即可。
- **付款周期**:月付 / 季付 / 年付。
- **车牌号(可选)**:点一下会弹出车牌专用键盘——先选省份简称(沪、京、浙…),再选字母,最后数字字母混排;普通车牌 7 位、新能源车牌 8 位,位数不对点确定会有提示。
- **共同居住人(可选)**:点「+ 添加同住人」,每个同住人要填**完整身份证号和手机号**(必须填完整,不然签约时会跳过这个人)。写错的卡片右上角垃圾桶图标可删除。
- **佣金(可选)**:给了中介就填。
- **附加费用项(可选)**:比如每月固定网费 30 元,点「+ 添加费用项」,写名称和金额,以后每期账单会自动带上。

全部填完点底部蓝色「确认签约」。

**签约成功后会弹出一个二维码**——**截图转发给租客**,让租客用微信扫码并关注公众号。租客一关注,账号就自动绑定,后面的账单提醒、在线支付、报修都能用了。点「完成」进入租约详情页。

## 6. 入住交接(必须做,而且要在电子签约之前)

**位置**:租约详情页 → 「交接记录」区域 → 「新增交接记录」

1. 类型选「入住交接」。
2. 点「预填默认物品清单」,系统自动带入合同签约设置里配好的物品,你只需要核对每项的**数量**和**状况**(默认填"完好")。没配置过清单就手动「+ 添加检查项」逐条填。
3. 备注可写可不写。点「确认」。

**注意**:
- **什么都不填不能提交**(系统和合同都要求有物品清单)。
- 每一条交接记录都可以随时点旁边的编辑/删除图标修改。
- 合同附件三(物品交接单)会自动使用这份记录,**所以必须先做完入住交接,才能生成电子签约**——顺序反了系统会直接拒绝并提示。

## 7. 电子签约(线上签合同)

**位置**:租约详情页 → 「电子签约」区域 → 「生成电子签约」

弹窗里的水电表底数等按实际情况填(可留空),点生成后,签约走四个状态,页面会显示当前状态和该做的事:

| 状态 | 你要做什么 |
|------|-----------|
| 待扫码 | 把页面上的**二维码截图发给租客**,租客扫码关注公众号 |
| 已关注 | 点「发起签署」(这时才真正调微签,开始计费) |
| 已发起签署 | 把「直接签署二维码」转发给租客,租客扫码完成实名+签字。如果租客说签完了但状态没变,点「下载查看签署进度」核实,确认无误后点「确认已签署」 |
| 已签署 | 点「查看/下载合同」,可把 PDF 发给租客 |

**注意**:
- 发起签署需要消耗微签额度(按份计费),发错不要反复发起。
- 如果状态显示异常(提示去微签后台核对),**不要再次发起**,联系系统维护人员。

## 8. 收款与账单

账单是**自动生成**的:签约后系统每天凌晨自动把接下来 7 天内开始的账期账单做好(月租金+附加费;后续版本升级后,租客签完合同立刻出第一期账单,包含押金)。你不用手工建账单。

**租客怎么交钱**:租客在租客端点账单,直接微信支付,钱自动到账,账单自动变"已付"。**这一条线全自动,你什么都不用做。**

**线下收款怎么记**(现金/银行转账):
「账单」→ 点开那张账单 → 「手动记账(现金/转账)」,选渠道、填金额(不填就是账单全额)和付款日期 → 记账成功,账单立即变已付。

**待确认收款**:工作台这个数字不为 0 时,点进去逐条「确认」或「驳回」。

**催缴**:
- 单笔催:账单详情 → 「📢 催一下」,租客微信立刻收到催缴提醒(带付款链接,点开就能交)。
- 批量催:「工作台 → 逾期账单」→ 右上角「批量催」,勾选多间一起发。

**其他账单操作**(都在账单详情页):
- **追加费用项**:补收其他费用。
- **追加滞纳金**:仅逾期账单有此按钮,金额默认为一个月租金,可后端配置。

## 9. 租客端能自己做什么(不用你跑腿)

- 看账单、微信支付、下载已签合同
- 在线报修(你会收到申请)
- 申请退租、申请换租(都要你审批)

这些申请都会出现在「工作台 → 待处理申请」里,点进去处理:
- **报修**:可标记"处理中/已完成",完成时可填维修费用。
- **退租**:显示建议违约金,**可以调整**,确认后批准或驳回。批准后系统自动处理账单和房间状态。
- **换租**:批准后系统自动给新房间生成电子签约流程。

## 10. 退租与续签(房东主动发起)

都在租约详情页底部:

- **退租**:填实际退租日期、押金退还金额、扣除原因(如扣 200 元清洁费)。退租后房间自动变回空置,未结清账单保留可继续追缴。
- **续签**:填新的到期日,可同时改新租金。

## 11. 报表与日常管理

- **经营报表**(我的 → 经营报表):按月看应收/实收/收缴率/净收益、按楼栋汇总、支出分类、空置率、押金台账。月份栏填 2026-07 这样的格式。
- **维修记录**(我的 → 维修记录):右上角「+」新增,房间 ID 填房间详情页看不到的数字时要找维护人员,日常建议直接从租客报修走。
- **支出管理**(我的 → 支出管理):记房租以外的开销(网费/工资/维修材料),支持编辑和删除。
- **群发通知**(我的 → 系统设置 → 群发通知):写标题+内容,选全部公寓或某公寓发送。**注意**:走微信客服消息通道,只有最近 48 小时内和公众号互动过的租客能收到,发送后页面会显示实际成功/失败数量。
- **白名单管理**(我的 → 系统设置 → 白名单管理):控制哪些微信号能进房东端,新加家人在这里操作。

## 常见问题

**Q:租客说没收到账单提醒?**
提醒只在到期前 3 天、到期当天、逾期后每 3 天自动发;租客必须先关注公众号且账号已绑定(租约详情页"绑定状态"可以看到)。急的话直接在账单详情点「催一下」。

**Q:签约成功了但还没出账单?**
账单每天凌晨自动生成,当天签约要等第二天早上;新版升级后签完立即出账单,以系统实际表现为准。

**Q:点"生成电子签约"报"请先填写入住交接记录"?**
先去「交接记录」新增一条入住交接(见第 6 节),再回来生成。

**Q:同住人签约时被跳过了?**
同住人的姓名、完整身份证号、手机号缺一个都不行,补全后可在租约详情页"共同居住人"区域重新添加。

**Q:手滑点错了怎么办?**
删除类操作都有二次确认,看清楚再点。账单金额填错可以追加费用项修正;拿不准的先截图问维护人员,不要反复试。
